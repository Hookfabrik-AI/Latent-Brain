01 / Architecture

A learned model, not another black box.

Explicit boundaries keep neural guesses separate from verified outcomes. The experimental FlyBrain has recurrent state, learned action preferences, a budget head, and a latent one-step imagination module.

◎

Episode memory

A small GRU tracks internal state across observations within an episode, rather than treating every decision in isolation.

✧

Bounded imagination

A trainable hidden-state predictor supports hypothetical rollouts. Simulation never substitutes for real execution.

↗

Learned priorities

Policy and budget heads propose actions and 1, 2 or 4 thinking steps. The budget labels are currently heuristic proxies.

03 / Get started

Run it locally in minutes.

Python 3.10+ and PyTorch. CPU execution is supported; training time varies by hardware.

Terminal · Linux / macOS
git clone https://github.com/Hookfabrik-AI/Latent-Brain.git
cd Latent-Brain
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[test]'
python -m pytest -q
python -m latent_brain demo-fly \
  --fly-checkpoint examples/pretrained_fly_v0.3.pt \
  --checkpoint examples/pretrained_v0.1.pt

Experiment protocol ↗
Open research, honest claims. No general reasoning breakthrough is claimed. No network access or private agent integrations are required. Proposed actions are not proof of execution. Better results must survive held-out tasks and equal-budget comparisons.
