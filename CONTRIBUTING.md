# Contributing

Contributions are welcome. Please keep this code independent of private products and data. Submit a focused issue or pull request with:

- a reproducible seed and exact commands
- expected vs observed results
- tests (including negative and held-out cases)
- measured CPU/memory use for performance claims

Do not contribute proprietary source code, private execution traces, credentials, or identifiable user data. If a claimed benchmark improvement is not statistically supported, label it experimental.
